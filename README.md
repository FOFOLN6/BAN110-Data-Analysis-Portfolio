# BAN110 Data Analysis Portfolio

This repository contains data analysis projects completed in BAN110. The projects demonstrate introductory skills in Python, probability, descriptive statistics, data visualization, and exploratory data analysis.

## Projects

### 01 — CDC BRFSS Health Data Analysis

Exploratory analysis of 20,000 responses from the CDC Behavioral Risk Factor Surveillance System.

**Skills:** Python, pandas, descriptive statistics, data filtering, BMI analysis, and data visualization.

[View Project 01](./01-cdc-brfss-health-data-analysis/)

### 02 — Kobe Bryant Hot Hand Simulation

A probability simulation comparing Kobe Bryant's shooting streaks with those of an independent shooter.

**Skills:** probability, random simulation, NumPy, custom Python functions, streak analysis, and visualization.

[View Project 02](./02-kobe-bryant-hot-hand-simulation/)
